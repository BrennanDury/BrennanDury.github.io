# Brennan Dury

A plain HTML and CSS personal site designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository. Name it `BrennanDury.github.io` for the root URL, or use any repository name for a project URL.
2. Push this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The site has no build step or dependencies.
